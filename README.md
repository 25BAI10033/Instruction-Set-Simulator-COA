# Instruction Set Simulator (COA)

## Description
This project is a C++ based Instruction Set Simulator developed for the Computer Organization and Architecture (COA) course.
It accepts an arithmetic expression in infix form, converts it into postfix notation, and generates instructions for different instruction formats.

## Features
- Expression Validation
- Infix to Postfix Conversion
- Operand Value Input
- Expression Evaluation
- 3 Address Instruction Format
- 2 Address Instruction Format
- 1 Address Instruction Format
- 0 Address Instruction Format
- Instruction Count Comparison

## Technologies Used
- C++
- Stack
- Map
- Set
- String

## Example Expression
(A+B)*(C-D)

## Output
The simulator generates:
- 3 Address Code
- 2 Address Code
- 1 Address Code
- 0 Address Code
- Instruction Count for each format
